# Contributing

Use Python 3.11 or later. Install with `python -m pip install -e '.[dev]'`.
Run `python -m unittest discover -s tests -v`, `ruff check .`, and `ruff format --check .`.
Keep tests offline and include numerical expectations or parser fixtures for behavior changes.
Do not submit client data, credentials, or proprietary text. Describe assumptions in the README.
Code contributions use Apache-2.0; original example data uses CC BY 4.0.
